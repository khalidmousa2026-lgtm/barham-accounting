# برهم — حسابات المشاريع (نسخة جديدة من الصفر)

واجهة عربية RTL متجاوبة للموبايل والكمبيوتر. تشمل اسم المشروع وصاحب المشروع والمبلغ المستلم والمبلغ المصروف ونسبة العمل اليدوية، وتحسب المتبقي تلقائياً، مع سجل استلام وصرف حسب التاريخ.

## ربط الحفظ السحابي بـ Supabase

1. أنشئ مشروع Supabase جديداً.
2. من SQL Editor نفّذ كامل محتوى `supabase/schema.sql`.
3. من Project Settings → API انسخ Project URL ومفتاح `anon` أو publishable key.
4. انسخ `.env.example` إلى ملف باسم `.env` في جذر المشروع، ثم ضع القيم الصحيحة:

   ```env
   VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
   ```

5. شغّل محلياً: `npm install` ثم `npm run dev`.
6. للنشر على Vercel أو استضافة Vite، أضف متغيري البيئة نفسيهما في إعدادات المشروع ثم أعد النشر.

## تنبيه أمان مهم

مخطط SQL الحالي للتجربة الأولية ويترك RLS غير مفعّل لتسهيل الاختبار، لذلك لا تنشر قاعدة البيانات للعامة ببيانات حقيقية قبل إضافة تسجيل دخول وسياسات Row Level Security مناسبة. لا تضع `service_role` key في الواجهة أو في ملف `.env` الخاص بالواجهة.

## سلوك التطبيق

- إضافة مشروع جديد يبدأ بنسبة عمل 10% ويمكن تعديلها يدوياً من 0 إلى 100.
- كل عملية استلام أو صرف تُسجل بتاريخها وبيانها وتحدّث الإجمالي تلقائياً.
- حذف المشروع يحذف حركاته المرتبطة بسبب `on delete cascade`.
- إذا لم تُربط بيانات Supabase، تعرض الواجهة تنبيهاً ولا تدّعي حفظ البيانات.
